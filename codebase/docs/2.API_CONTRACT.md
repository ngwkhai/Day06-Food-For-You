# API Contract — Xanh SM Ngon Lunch Chatbot

## 1. Mục tiêu

Tài liệu này định nghĩa contract giữa `frontend/` và `backend/`.

Frontend chỉ cần gọi đúng API theo contract này. Backend phải đảm bảo response trả về đúng format để frontend hiển thị được chatbot, câu hỏi làm rõ và danh sách món gợi ý.

## 2. Base URL

### Local development

```text
http://localhost:8000
```

### Environment variable phía frontend

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## 5. POST /api/recommend

Endpoint chính để user gửi nhu cầu ăn trưa và nhận gợi ý món.

```json
{
  "message": "Mình có 1 tiếng nghỉ, cần món nóng dưới 80k, không cay",
  "constraints": {}
```

| Field         | Type   | Required | Mô tả                                       |

## 7. Frontend Handling Rules

Frontend cần xử lý theo `status`.

### Nếu `status = "ok"`

Hiển thị:

* `assistant_message`.
* Danh sách `recommendations`.
* Mỗi món là một `FoodCard`.

### Nếu `status = "need_clarification"`

Hiển thị:

* `assistant_message`.
* Danh sách `questions`.
* Không hiển thị food cards.

### Nếu `status = "no_result"`

Hiển thị:

* `assistant_message`.
* Các câu hỏi/gợi ý nới điều kiện.
* Có thể cho user nhập lại tiêu chí.

### Nếu `status = "error"`

Hiển thị lỗi ngắn gọn:

```text
Có lỗi xảy ra. Vui lòng thử lại.
```

## 8. Backend Logic Requirements

Backend cần đảm bảo:

1. Parse được thời gian:

   * “1 tiếng” → `60`
   * “35 phút” → `35`
   * “chỉ còn 45 phút” → `45`

2. Parse được ngân sách:

   * “dưới 80k” → `80000`
   * “khoảng 60 nghìn” → `60000`

3. Parse được khẩu vị:

   * “không cay” → `avoid_spicy = true`
   * “món nóng” → `prefer_hot = true`
   * “ăn nhẹ” → `meal_size = "light"`
   * “ăn no” → `meal_size = "full"`

4. Với input mơ hồ, không được đoán bừa. Phải trả `need_clarification`.

5. Với correction, phải cập nhật constraint cũ bằng thông tin mới.

## 9. Example Frontend Call

```ts
export async function recommendFood(message: string, constraints = {}) {
  const res = await fetch(`${process.env.NEXT_PUBLIC_API_URL}/api/recommend`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      message,
      constraints
    })
  });

  return res.json();
}
```

## 10. Demo Test Inputs

### Happy path

```text
Mình có 1 tiếng nghỉ, căng tin đông, cần món nóng dưới 80k, không cay.
```

Expected:

```text
status = ok
recommendations.length = 3
```

### Low-confidence path

```text
Ăn gì nhanh cũng được.
```

Expected:

```text
status = need_clarification
questions.length <= 3
```

### Correction path

```text
Chỉ còn 35 phút, không ăn cay.
```

Expected:

```text
status = ok
recommendations chỉ gồm món ETA an toàn và không cay
```
