# 1. Folder Structure

## Mục tiêu

Repo được chia theo hướng monorepo để các thành viên có thể làm song song:

* `frontend/`: giao diện chatbot, gọi API backend.
* `backend/`: API xử lý message, parse ràng buộc, gọi recommendation logic.
* `data/`: mock data món/quán, schema dữ liệu, script validate.
* `docs/`: tài liệu sản phẩm, API contract, test plan, demo script.

Workflow kết nối chính:

```text
data/ → backend/ → frontend/ → demo
```

## Phân công theo folder

| Folder      | Người phụ trách | Nhiệm vụ chính                          |
| ----------- | --------------- | --------------------------------------- |
| `frontend/` | Huy             | UI chatbot, food cards, gọi API backend |
| `backend/`  | Dương hoặc Khải | API, parse input, recommend endpoint    |
| `data/`     | Đạt             | Mock data, schema, validate data        |
| `docs/`     | Khải + Dương    | API contract, test plan, demo script    |

## Quy tắc làm việc để tránh conflict

1. Người phụ trách folder nào thì ưu tiên chỉ sửa folder đó.
2. Nếu cần đổi API response/request, phải cập nhật `docs/API_CONTRACT.md`.
3. Nếu cần đổi field trong món ăn, phải cập nhật `docs/DATA_SCHEMA.md` và `data/schema.md`.
4. Frontend không đọc trực tiếp `data/mock_foods.json`; frontend chỉ gọi backend.
5. Backend không tự ý đổi data schema nếu chưa báo người làm data.
6. Mọi nhánh feature merge vào `develop`, sau khi test ổn mới merge vào `main`.

## Branch đề xuất

```text
main
└── develop
    ├── feature/frontend
    ├── feature/backend
    ├── feature/data
    └── feature/docs-demo
```

## Thứ tự tích hợp

```text
1. feature/data → develop
2. feature/backend → pull develop → connect data → test API → develop
3. feature/frontend → connect backend API → test UI → develop
4. develop → test 4 demo paths → main
```

## Lệnh chạy dự kiến

### Chạy data validation

```bash
cd data
python validate_data.py
```

### Chạy backend

```bash
cd backend
npm install
npm run dev
```

Backend mặc định chạy ở:

```text
http://localhost:8000
```

### Chạy frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend mặc định chạy ở:

```text
http://localhost:3000
```

## Environment variables

## Definition of Done

Repo được xem là sẵn sàng demo khi:

* `data/mock_foods.json` có ít nhất 10 món hợp lệ.
* Backend gọi được `/api/recommend`.
* Frontend gửi message được tới backend.
* UI hiển thị được 3 món gợi ý.
* Demo được 4 paths:

  * Happy path.
  * Low-confidence path.
  * Failure path.
  * Correction path.
